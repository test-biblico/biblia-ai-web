# 1. INTRODUCCIÓN AL SISTEMA HEOS

HEOS (Hermes Enterprise Operating System AI) es un sistema empresarial compuesto por agentes especializados de inteligencia artificial que trabajan coordinadamente para administrar, analizar y optimizar una empresa de alquiler de maquinaria pesada.

El sistema funciona como una empresa digital paralela:

-  Un Director General IA. 
-  Directores departamentales IA. 
-  Analistas especializados. 
-  Automatizaciones. 
-  Base de datos empresarial. 
-  Dashboard ejecutivo. 

---

# 2. OBJETIVO FINAL DEL SISTEMA

El objetivo de HEOS es que el dueño pueda responder en segundos:

## Preguntas estratégicas:

"¿Cómo está la empresa hoy?"

"¿Qué máquinas generan más dinero?"

"¿Cuál máquina está perdiendo dinero?"

"¿Dónde estamos gastando demasiado?"

"¿Qué cliente es más rentable?"

"¿Qué decisiones debo tomar esta semana?"

"¿Qué problemas podrían aparecer antes de que ocurran?"
