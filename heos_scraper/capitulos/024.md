# 1. OBJETIVO DEL MÓDULO

Este documento define la **Biblioteca Universal de KPIs** que utilizará HEOS-AI.

Cada agente, dashboard, workflow y reporte utilizará estos indicadores como lenguaje común para medir el desempeño de la empresa.

El objetivo no es mostrar cientos de métricas, sino identificar **las pocas que realmente impulsan la rentabilidad y el crecimiento**.

# 17. HEOS ENTERPRISE SCORE (NUEVO CONCEPTO)

Este será el indicador principal de todo el sistema.

Escala:

0-100.

Se calculará ponderando:

- Finanzas (25 %).
- Operaciones (20 %).
- Comercial (15 %).
- Mantenimiento (15 %).
- Clientes (10 %).
- RRHH (5 %).
- Seguridad (5 %).
- IA y Automatización (5 %).

Interpretación:

- 90-100 → Empresa excelente.
- 80-89 → Muy buena.
- 70-79 → Buena, con oportunidades.
- 60-69 → Atención.
- Menor a 60 → Riesgo alto.

Será el primer indicador visible para el Director General.
