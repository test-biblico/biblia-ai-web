# HEOS-DATA-CORE

## MOTOR CENTRAL DE DATOS EMPRESARIALES

### Single Source of Truth (SSOT)

---

# 1. OBJETIVO DEL DOCUMENTO

Este documento define el corazón del sistema HEOS-AI.

Todos los agentes creados en Hermes dependerán de un único repositorio central de información.

**Regla fundamental:**

> **Un dato se registra una sola vez y toda la empresa utiliza esa misma información.**

Esto evita:

- Información duplicada.
- Versiones diferentes.
- Errores humanos.
- Decisiones incorrectas.

---

# 2. PRINCIPIOS DEL DATA CORE

El HEOS-DATA-CORE se basa en ocho principios.

## 1. Fuente Única de Verdad

Ejemplo:

La excavadora MAQ-032 tiene un solo registro.

No puede existir:

- Un código diferente en ventas.
- Otro en mantenimiento.
- Otro en contabilidad.

Toda la empresa consulta exactamente el mismo activo.

---

## 2. Datos Relacionados

Todo está conectado.

Ejemplo:

Cliente

↓

Contrato

↓

Máquina

↓

Operador

↓

Proyecto

↓

Facturación

↓

Cobranza

↓

Rentabilidad

Si un cliente deja de pagar, Hermes puede calcular automáticamente el impacto financiero y operativo.

---

## 3. Trazabilidad Total

Cada modificación queda registrada.

Ejemplo:

Quién modificó.

Qué cambió.

Cuándo.

Por qué.

Valor anterior.

Valor nuevo.

---

## 4. Datos Históricos

Nunca se eliminan registros críticos.

Se archivan.

Esto permite:

- Comparar años.
- Detectar tendencias.
- Entrenar modelos predictivos.

---

## 5. Calidad de Datos

Hermes verificará automáticamente:

- Datos faltantes.
- Datos duplicados.
- Valores imposibles.
- Errores de formato.
- Inconsistencias.

---

## 6. Seguridad

Cada usuario verá únicamente la información autorizada.

Ejemplo:

Un operador no podrá acceder a:

- Nómina.
- Costos financieros.
- Rentabilidad.

---

## 7. Escalabilidad

El sistema debe soportar:

- Miles de máquinas.
- Millones de registros.
- Décadas de historial.

---

## 8. Inteligencia Compartida

Todos los agentes consultan la misma información.

No existen bases de datos independientes.

# 10. MEMORIA COMPARTIDA ENTRE AGENTES

"¿Esta máquina está disponible?"

# 12. MODELO DE CALIDAD DE DATOS

Cada noche Hermes ejecutará un análisis automático.

Revisará:

- Registros incompletos.
- Datos duplicados.
- Contratos sin cliente.
- Máquinas sin ubicación.
- Facturas sin contrato.
- Órdenes sin cierre.
- Repuestos sin costo.
- Horómetros inconsistentes.

Generará un informe con un **Índice de Calidad de Datos (ICD)** de 0 a 100.
