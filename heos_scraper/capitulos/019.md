# HEOS-UNIVERSAL DATA MODEL (UDM)

# MODELO UNIVERSAL DE DATOS EMPRESARIALES

## "Un solo lenguaje para toda la empresa"

---

# 1. OBJETIVO DEL MÓDULO

El **HEOS-UNIVERSAL DATA MODEL (UDM)** será el "ADN" de toda la plataforma.

Su función es definir un lenguaje único para todos los agentes, dashboards, reportes, automatizaciones e integraciones.

**Ningún agente podrá crear datos con una estructura diferente al UDM.**

Esto evitará:

- Información duplicada.
- Campos incompatibles.
- Datos contradictorios.
- Integraciones complejas.
- Errores entre departamentos.

---

# 2. PRINCIPIOS DEL MODELO

Todo dato deberá cumplir estas reglas:

- Un identificador único global (UUID).
- Fecha y hora de creación.
- Fecha y hora de modificación.
- Usuario o agente que realizó el cambio.
- Estado del registro.
- Historial de versiones.
- Nivel de confidencialidad.
- Nivel de calidad del dato.

# 13. PROPUESTA DE MEJORA (NUEVO CONCEPTO)

## HEOS KNOWLEDGE GRAPH

Además de la base de datos relacional, Hermes construirá un **Grafo de Conocimiento Empresarial**.

En lugar de almacenar únicamente tablas, comprenderá las relaciones entre todos los elementos del negocio.

Ejemplo:

Cliente Alfa

↓

Contrató

↓

Proyecto Minero Norte

↓

Utilizó

↓

Excavadora MAQ-022

↓

Operada por

↓

Juan Pérez

↓

Requirió

↓

Mantenimiento Preventivo

↓

Con repuestos del

↓

Proveedor Industrial XYZ

Gracias a este grafo, Hermes podrá responder preguntas complejas en segundos.

Ejemplos:

- ¿Qué proveedor está relacionado con la mayor cantidad de fallas?
- ¿Qué operadores trabajan con las máquinas más rentables?
- ¿Qué tipo de proyecto genera más desgaste en determinado modelo de excavadora?
- ¿Qué clientes utilizan equipos con mayor costo de mantenimiento?

Este enfoque convertirá los datos en conocimiento conectado, facilitando análisis avanzados y recomendaciones más precisas.
